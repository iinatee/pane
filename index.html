Pane

A light, glassy player for your Spotify Premium account. Connect it once and it remembers you.

Pane has to be opened from its web address (for example your GitHub Pages link), not as a file on your computer. Spotify can't sign you in otherwise.

  1. Open the Spotify Developer Dashboard and create an app. Any name and description will do.
  2. Under Redirect URIs, add this exact address:
  3. Tick Web API and Web Playback SDK, save, then copy the app's Client ID into the box below.
